# Quickstart

Five minutes to a verified delivery.

## Install

Requires Python ≥ 3.10 and Poetry.

```bash
git clone git@github.com:Skelf-Research/tessera.git
cd tessera
poetry install
poetry run pytest tests/ -q             # expect: 151 passed
```

## Generate and verify a proof (in-process)

```python
from tessera.crypto.crypto_utils import CryptoUtils
from tessera.crypto.blinding import BlindedSender, BlindedVerifier

# One-time per sender: long-term keypair.
x, Y, _ = CryptoUtils.generate_keypair()

# Enrolment (pairwise, out-of-band): both ends agree on a contact seed.
seed = b"shared-with-this-recipient"

# Sender produces a delivery proof under a per-recipient blinded pseudonym.
sender = BlindedSender(x, Y)
proof = sender.prove(seed, session_id="msg-001",
                     metadata={"channel": "message"})

# Recipient authenticates the blinded pseudonym against the enrolment record.
verifier = BlindedVerifier()
ok = verifier.authenticate(proof, contact_public_key=Y,
                           shared_seed=seed, session_id="msg-001")
assert ok   # True
```

A different seed (any other recipient) cannot recompute the pseudonym, so the
sender's deliveries to *different* recipients are unlinkable.

## Run a node over WebSocket

```bash
poetry run python -m tessera.network.ws_server --port 8100
```

A client (Python or the cross-platform SDKs in `sdks/`) connects and exchanges
`subscribe` / `proof` / `fetch` / `stats` / `ping` JSON messages. See
[`api.md`](api.md) for the wire protocol.

## Local cluster (mesh or ring, with runtime churn)

```bash
poetry run python -m tessera.deploy.cluster --nodes 5 --topology ring
```

Programmatically, use `tessera.deploy.cluster.LocalCluster` — it supports
`stop_node` / `start_node` for churn experiments. See
[`decentralized-architecture.md`](decentralized-architecture.md).

## Reproduce paper experiments

Each experiment in the paper is regenerated by a harness in `scripts/`; outputs
land in `../tessera-paper-msg/results/`. Full mapping:
[`../../tessera-paper-msg/ARTIFACT.md`](../../tessera-paper-msg/ARTIFACT.md).
Headline:

```bash
poetry run python scripts/bench_crypto.py                       # E1
poetry run python scripts/bench_security.py --trials 5000       # E6
poetry run python scripts/analysis/anonymity_sim.py             # E2
poetry run python scripts/analysis/linkability_sim.py           # E3
poetry run python scripts/analysis/churn_sim.py --nodes 8       # E5
poetry run python scripts/analysis/leakage_compare.py           # E7
```
