💻 Integration Code Examples

Basic Setup:

// Initialize Tessera import { TesseraClient, TesseraWidget } from '@tessera/web'; // Initialize the client TesseraClient.initialize({ apiKey: 'your-api-key', enableLogging: true }); // Create widget const widget = new TesseraWidget('#widget-container');

Verify Incoming Call:

// Verify an incoming call const result = await TesseraClient.getInstance().verifyIncomingCall({ callerId: '+1234567890', callType: 'WEBRTC_CALL', sessionId: 'unique-session-id' }); if (result.isVerified) { console.log('✅ Verified caller:', result.callerInfo); } else { console.log('⚠️ Unverified call'); }

React Integration:

import { useTesseraVerification } from '@tessera/web'; function CallInterface({ callContext }) { const { verificationResult, isLoading } = useTesseraVerification(callContext); return ( <div> {isLoading ?
